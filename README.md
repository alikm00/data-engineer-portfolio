# data-engineer-portfolio

پورتفولیوی پروژه‌های مهندسی داده‌ی علی

## درباره
در این مخزن پروژه‌هایی که برای یادگیری و نمونه‌کار ایجاد کردم قرار دارن. هدف: نشان دادن توانایی‌ها در Python, Pandas, SQL, ETL, Airflow, PySpark و Cloud.

## ساختار پروژه
- `01-python-basics/` — اسکریپت‌های پایه پایتون
- `02-pandas-project/` — Jupyter Notebook تحلیل داده
- `03-sql/` — اسکریپت‌ها و کوئری‌های PostgreSQL
- `04-etl-airflow/` — pipeline با Docker و Airflow
- `05-pyspark/` — jobهای PySpark
- `06-cloud/` — مستندات و دستورالعمل اجرای نمونه در GCP
